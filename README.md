# Game Showcase — 縦置きタッチモニター用メニュー画面

32インチ縦置きのAndroidタッチモニターで動くゲーム／動画の紹介メニューです。
ビルド作業は不要で、`index.html` をブラウザで開くだけで動きます。
インターネットがある設置先では GitHub Pages の公開 URL を開くのが最も確実です
（→ 2章）。オフラインでも動きます。

> **なぜそうなっているか**（設計時の判断理由・実測値・既知の落とし穴）は
> [DESIGN-NOTES.md](DESIGN-NOTES.md) にまとめてあります。
> 数値を調整する前や、実機で問題が出たときはそちらも確認してください。

---

## 1. できること

- ゲームサムネ5枚＋動画1本の **計6枚を3Dリングでクルクル回転**
- 放っておくとゆっくり自動回転、**スワイプすると勢いよく回る**（慣性つき）
- 各カードが少しずつズレたタイミングで **ゆらゆら** 揺れる
- 奥のカードは小さく・暗く・ぼやけ、**正面のカードだけがくっきり光る**
- 配色は **白地の明るいトーン**。ライトグレーの下地に白いカードが浮き、
  差し色は `#4FADBB` の1色だけを、正面カードの光る枠・バッジ・ドット・
  見出し下のテキストに使っています
- 正面から離れたカードは小さく・薄く・ぼやけ、**真横より奥のカードは完全に消えます**
  （白地では奥のカードまで見えてしまい、画面が雑然とするため）
- 回転には緩急があり、**各カードが正面に来ると少し溜まって**から次へ進みます
- 正面に来た作品の **タイトルが画面下に大きく** 表示される
- カードを **タップすると、そのカードがそのまま拡大して全画面の説明** になる
- 動画カードをタップすると **その場で全画面再生**

## 2. 使い方（モニターへの設置）

### A. インターネットがある場合（推奨）

公開 URL をモニターの Chrome で開くだけです。ファイルのコピーは不要です。

```
https://ty-gh.github.io/game-showcase/
```

- 公開元は public リポジトリ `ty-gh/game-showcase`（GitHub Pages）。
  **正本はこの `ws-remote/game-showcase/` フォルダ**で、内容を変えたら
  公開リポジトリへコピーして push すると数分で反映されます。
- GitHub は 1 ファイル **100MB まで**。動画は `ffmpeg` で H.264 3Mbps 程度に
  圧縮してから置きます（元 240MB → 84MB の実績あり）。
- 右上の `⛶` ボタンで全画面になります。

### B. オフラインで使う場合

1. この `game-showcase` フォルダごとモニター本体の **`Download` フォルダ**にコピーします
   （USBメモリやSDカードからのコピーでOK。PairDrop などの転送アプリは
   フォルダ構造が崩れるので使わない）。
2. Chrome のアドレスバーに次を **直接入力**して開きます：
   ```
   file:///sdcard/Download/game-showcase/index.html
   ```
   ストレージへのアクセスを求められたら許可します。
3. 右上の `⛶` ボタンで全画面になります。

> **⚠ ファイルアプリから `index.html` をタップして開くと画像が出ません。**
> その開き方だと `content://` という形式で渡され、`images/` `videos/` への
> 相対パスが解決できなくなるためです。アドレスバーが `content://` で始まって
> いたらこれが原因なので、上記の `file://` で開き直してください。

> **アドレスバーを完全に消したい場合**
> 「Fully Kiosk Browser」などのキオスクブラウザアプリを使うと、
> 電源を入れたら自動でこの画面が全画面表示される、という運用にできます。
> Start URL に A の公開 URL か B の `file://` パスを入れるだけで、
> 中身のHTMLは変更せずそのまま使えます。

## 3. 画像の差し替え

`images/` フォルダに、**決まった名前で置くだけ**です。

| 置く場所 | 対応するカード |
|---|---|
| `images/game1.jpg` | 1枚目 |
| `images/game2.jpg` | 2枚目 |
| `images/game3.jpg` | 3枚目 |
| `images/game4.jpg` | 4枚目 |
| `images/game5.jpg` | 5枚目 |
| `images/video1.jpg` | 動画1のサムネ |

- 拡張子は `.jpg` `.jpeg` `.png` `.webp` `.svg` のどれでも使えます。
  この順で探して、**最初に見つかったものを表示**します。
- いま入っているのは仮のダミー画像（`.svg`）です。
  同じ名前の `.jpg` を置けば、そちらが優先されるので **ダミーを消す必要はありません**。
- 推奨サイズは **横長 16:9（例：1920×1080）**。違う比率でも自動で切り抜いて表示します。

---

## 4. 動画の差し替え

`videos/` フォルダに置きます。

| 置く場所 | 対応するカード |
|---|---|
| `videos/video1.mp4` | 動画1 |

- 対応形式は `.mp4` `.webm` `.m4v`。**H.264 の mp4** が最も確実です。
- ファイルを置くまでは、再生画面に「ファイルを置いてください」と案内が出ます。

## 5. タイトル・説明文の変更

`index.html` をテキストエディタ（メモ帳でも可）で開き、
**`★★★ ここだけ書き換えれば内容が変わります ★★★`** と書かれた部分を編集します。

```js
{
  id: "game1",                 // images/game1.jpg を読みます
  type: "game",                // "game" か "video"
  title: "ゲームタイトル 1",    // ← ここを書き換え
  desc:  "ここに説明文が入ります。\n改行もそのまま反映されます。"
},
```

- `\n` と書くと改行になります。
- タイトルの下に一言添えたいときは `sub: "〜",` を1行足します（省略可。省略すると何も出ません）。
- **6枚目以降を足したいとき**は `{ ... },` のブロックを丸ごとコピーして貼り付け、
  `id` を `game6` などに変えるだけです。枚数に制限はありません。
  リングの間隔は自動で計算し直されます。
- **動画を増やすとき**は `type: "video"` にして `id` を `video3` などにします。

## 6. 配色の変更

基調は白黒で、差し色は1色だけです。`index.html` の次の行を変えると、
正面カードの光る枠・バッジ・ドット・タイトル下のテキスト・背景のにじみが
まとめて変わります。

```js
const ACCENT = "#4FADBB";
```

特定のカードだけ色を変えたい場合は、そのカードの `{ ... }` の中に
`accent: "#xxxxxx",` を1行足してください（省略したカードは `ACCENT` を使います）。

明るさや文字色そのものを変えたい場合は、`index.html` 冒頭の CSS を編集します。

```css
--bg:      #dce3e4;   /* 画面の下地。カードの白を浮かせるため少しグレーです */
--surface: #ffffff;   /* カード・モーダルの面 */
--ink:     #16191a;   /* 見出しと本文 */
--ink-2:   #566063;   /* 補足の文章 */
--ink-3:   #949fa1;   /* さらに薄い文字・ドット */
```

> `--bg` を白 (`#ffffff`) に近づけるほど、カードとの境目が曖昧になって
> 画面が霞んで見えます。カードを浮かせたいときは `--bg` を少し暗くしてください。

## 7. 動きの調整

同じく `index.html` 内の `CONFIG` を書き換えます。

```js
const CONFIG = {
  autoSpeed:   0.032,  // 自動回転の速さ。0 にすると止まります
  dragSense:   0.30,   // スワイプの効き。大きいほどよく回ります
  friction:    0.945,  // 勢いの減り方。1に近いほど長く回り続けます
  maxBlur:     7,      // 奥のカードのぼかし量(px)。0 にすると動作が軽くなります
  detent:      0.55,   // 回転の緩急。カードが正面に来ると遅くなり、間では速くなります
                       // 0 にすると一定速度でくるくる回り続けます（0〜0.9）
  snapToFront: false,  // true にすると、手を離したとき最寄りのカードで止まります
  idleResume:  2600,   // 操作後、自動回転に戻るまでの時間(ms)
  autoLite:    true    // 重い端末で自動的に効果を減らし、滑らかさを優先します
};
```

> `autoLite` を `true` のままにしておくと、実際のフレームレートを測って
> 動きが重いと判断したときに、ぼかし → 影 → ゆらゆら の順で自動的に効果を
> 落とします。設置先の端末の性能が分からない場合は、そのままにしてください。

見た目のサイズ感は、`index.html` 冒頭の CSS の `:root` で調整できます。

```css
--card-w: clamp(230px, 42vw, 620px);   /* カードの幅 */
--perspective: 2200px;                 /* 小さいほど奥行きが強調されます */
--tilt: -7deg;                         /* リングの傾き。0deg で真横から見た形に */
--bob: 12px;                           /* ゆらゆらの振れ幅 */
```

> **リングの半径は枚数から自動で決まります**（カード同士が3Dで交差して
> 切り合わない最小の半径 × 余裕）。密集させたい／ゆったりさせたいときは、
> `index.html` の `const RING_MARGIN = 1.15;` を変えてください
> （1.0 が交差しない下限。1.0 未満にするとカードが重なって切れて見えます）。
> カードを大きくすると、両隣のカードは画面の左右にはみ出します。

## 8. ファイル構成

```
game-showcase/
├── index.html      ← 本体（これ1つで動きます）
├── images/         ← サムネ画像を置く場所
│   ├── game1.svg 〜 game5.svg   （仮のダミー）
│   └── video1.svg               （仮のダミー）
├── videos/         ← 動画ファイルを置く場所（現在は空）
├── README.md       ← この文書（使い方）
└── DESIGN-NOTES.md ← 設計メモ（判断理由・実測値・未検証事項）
```

## 9. 動作環境

- Android 8 以降の Chrome / WebView
  （新しいCSS機能に依存しないよう、色の計算はすべて JavaScript 側で行っています）
- PC の Chrome / Edge / Safari でも同じように動くので、
  手元のパソコンで内容を確認してからモニターにコピーできます
- **インターネット接続は不要です。** 外部のライブラリやフォントは一切読み込みません
